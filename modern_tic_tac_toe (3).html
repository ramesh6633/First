How to Upload to GitHub Pages

Follow these simple steps to publish your web game live for free.

Step 1: Save your file

Save this complete code in a file named index.html inside a folder on your computer.

Step 2: Create GitHub Repository
  • Go to github.com/new and sign in.
  • Set Repository Name to tic-tac-toe.
  • Keep it set to Public.
  • Click Create repository.
Option A: Upload via Browser (Easiest)
  1. On your new repository page, click uploading an existing file.
  2. Drag and drop your index.html file.
  3. Click the green Commit changes button.
Option B: Upload via Git Terminal Commands

# Navigate to project folder

git init

git add index.html

git commit -m "Initial Tic Tac Toe commit"

git branch -M main

# Replace USERNAME with your GitHub handle

git remote add origin https://github.com/USERNAME/tic-tac-toe.git

git push -u origin main

Step 3: Enable Free Hosting (GitHub Pages)
  1. Inside your repository, go to Settings → Pages (left menu).
  2. Under Build and deployment / Branch, choose main branch and click Save.
  3. Wait 1 minute! Your live game URL will appear: https://USERNAME.github.io/tic-tac-toe/
